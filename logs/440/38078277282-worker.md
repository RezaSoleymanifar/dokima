**Agent:** I fixed the reviewer's one blocker (R1). The permission guard test from main, `tests/test_manifest.py::test_the_guard_passes_settings_the_manifest_declares`, passes again.

**The problem:** to pick the right installations link, `installations_link` in `dokima/agent.py` asked GitHub about the repo (`repos/{repo}`) to find out whether its owner is an organization. The manifest guard can't tie that call to any app permission, so that test went red.

**The fix:** it now asks about the owner instead (`users/{owner}`). That call needs no permission, and the manifest guard already accepts it. The answer is still "Organization" or "User", so organizations get the organization's installations page and personal accounts get their own.
