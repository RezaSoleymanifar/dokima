**The cause:** the plan checker's "every new test must fail first" step (`passing_today` in `dokima/planner.py`) runs each new test against the current files. - **201.2:** A new test that already passes on main is still rejected, on a first plan and on a re-plan. The reason names that test and says it passes today. Tests that fail on main are not named.
- **201.3 (non-functional):** The check leaves the branch, the worker's code and the planner's files exactly as it found them: same HEAD and branch, no extra worktree, no file added, lost or changed.
