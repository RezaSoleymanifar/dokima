**Agent:** I fixed the plan check so a re-plan made after the worker has built can be accepted again. That should free #158. All three of the plan's tests now pass, and so does the full suite (299 passed).

**What was wrong:** the check that "a new test must fail first" ran each new test on the issue's branch. On a re-plan that branch already holds the worker's code, so tests proving that code passed there and the plan was rejected.

**What changed:** the only file touched is `dokima/planner.py`.
- **New step:** `main_with_tests` copies main's code (the commit in `PLANNER_BASE`) into a temporary folder outside the repo. It then copies the branch's current `tests/` folder on top, which includes any helper files the planner added.
- **Changed check:** `passing_today` now runs each new test in that folder instead of on the branch. A new test that already passes on main is still rejected and named as "a new test that passes today". This holds on a first plan and on a re-plan.
- **Branch untouched:** the folder is deleted afterwards. The check never checks out main or adds a worktree, so the branch, its HEAD and its files stay as they were.

`work.json` is written to `/tmp/dokima-out`, and both hand-back checks pass. There were no open blockers to answer. Nothing outside the plan's scope changed, and I found no tests I think are wrong.
