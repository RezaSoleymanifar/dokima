> # Autopilot's reaction to an issue closing, usually because its pull request merged. Code reads every issue on
> # autopilot from GitHub: a parent whose last sub-issue closed closes too, saying its whole tree is done, and that
> # close counts one level up; a done tree (its top issue closed) goes off autopilot; and every issue left on autopilot
