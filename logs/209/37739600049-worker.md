  - A new `agent autopilot start|stop N` command prints the comment text.
- **`.github/workflows/commands.yml`**
  - The routing step passes the switch on to a new `autopilot` job. That job uses the app's token to change the labels, then posts one comment where the command was written (the pull request or the issue). The comment names every issue that was switched.
  - If the job fails, the existing "say why" step reports it.
  - Strangers and bots are stopped by the existing checks, so they change nothing.
