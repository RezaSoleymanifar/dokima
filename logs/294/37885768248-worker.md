**What changed:**

- **Who gets Blocker:** an open issue that blocks another open issue shows Blocker. Otherwise its pill follows its high or parked label. A closed issue never shows Blocker.
- **Scheduled run:** every 15 minutes the run checks every open issue and writes a pill only when it changes. That is how links changed by hand reach the board, since GitHub sends no event for a link.

- **High or parked label added:** if the card already shows Blocker, it keeps Blocker. The next scheduled run fixes any pill that is out of date.
- **When GitHub won't list an issue's links:** that issue's pill stays as it is and the other issues are still updated. The run then fails with exit code 1 and an error naming the issue and GitHub's answer.
- **AGENTS.md:** the Priority line in the board section now describes all of this.
