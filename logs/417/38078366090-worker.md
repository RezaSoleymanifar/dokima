**Agent:** I fixed the reviewer's blocker R2: when GitHub refuses a call while the run decides what comes next, the card goes back to its stage's column with Needs you, even while GitHub still can't be read. **What was wrong:** after my last round, a failed decision still wrote `board.txt`. Any run that leaves `board.txt` behind gets its card rebuilt from what GitHub says. With GitHub still refusing, that rebuild failed and left the card as it was, with no Needs you.

**The fix, in `dokima/agent.py`:**
- `board.txt` is still written, because the test for criterion 417.3 reads it.
- A failed decision now also leaves an `undecided` file next to it.
- When that file is there, the board step skips the rebuild from GitHub. Instead it puts the card in its stage's column with Needs you right away, the same way it handles a failed run.
