**Agent:** I've written the plan for #202 and its tests, and the hand-back check passes. The new tests are in `tests/test_board.py`. Six fail today because the feature is missing; the other 295 tests pass.

**User story:** an issue's priority label and its board Priority pill always agree, and no one sets the pill by hand.

**Acceptance criteria**
- **202.1:** Adding the blocker, high or parked label sets the pill to Blocker, High or Parked, and removing it clears the pill. Other labels never touch the pill. A priority label never moves the card or changes its Needs you pill. If an issue has two priority labels, the higher one shows (Blocker, then High, then Parked).
- **202.2:** An issue filed with a priority label lands on the board with its pill already set, which is what should have happened with #201. GitHub sends a "labeled" event for each label an issue is filed with, so this needs no extra trigger.
- **202.3:** A repo with no board, or a board with no Priority field, is left alone: nothing is written and nothing fails.

**Scope:** `dokima/board.py`, `.github/workflows/board.yml`, `AGENTS.md`, `tests/test_board.py`.

**Questions for you.** The plan assumes yes to the first and "higher label wins" to the second.
1. **The workflow change.** Clearing the pill on removal needs `unlabeled` added to the issue triggers in `.github/workflows/board.yml`, which today only runs on `labeled` and `closed`. The bot can't push workflow files, so you would have to push or approve that one line. May the work include it?
2. **Two priority labels at once.** Should the pill show the higher one? With that reading, removing blocker while high remains shows High, not an empty pill.

**Concern:** `AGENTS.md` line 74 says "Priority (Blocker) is a field, not a label", but this issue makes the label the source of the field. The plan has the worker update that line so the doc matches the code.

**Out of scope:** the Blocker pill from blocked-by links (#68), rebuilding the board from records (#135), and backfilling pills on issues already on the board.
