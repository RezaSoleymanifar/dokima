**What the worker built**
- Every 15 minutes, the sweep now redraws any issue card or PR card that doesn't show its issue's state now, whether the issue is open or closed. An update to either the issue or its PR redraws both cards. A card that's already right is left alone.

**Problem to file separately:** I also proposed a new issue for a gap this PR makes worse. Sometimes saving a card is refused because it would change the owner's part of the issue text. When that happens:
- the sweep posts a comment saying why, but the run still passes;
- its error line doesn't say which issue it was;
- that comment counts as an update to the issue, so the next sweep tries again and posts the same comment every 15 minutes.

A save is only refused when the new card itself contains the marker, which is rare. Before this change, nothing went back to such an issue unless a person acted on it. That's why it's a note and a proposed issue rather than a blocker.
