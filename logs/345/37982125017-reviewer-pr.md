- The card job runs for a merged pull request whoever merged it, including the bot on autopilot.
- The redraw runs from main's copy of `card.yml`, never the pull request's own code.

- All 5 new tests pass on the branch, and the full run had no failures (737 passed, 83 skipped).

**Why it's blocked (B1, criterion 345.1):** the plan lists "redrawing cards when a pull request is closed without merging" as out of scope. The new trigger fires on every close, and an older part of the job's `if:` lets any event a person sends through (`.github/workflows/card.yml:35`). I ran an unmerged close through the tests' own harness:

**Fix:**
1. The planner adds a test that a pull request closed without merging, by the owner or by the bot, does not run the card job.
2. The worker then stops pull-request-close events from getting through that last part of the `if:`, so only a merged pull request passes.
