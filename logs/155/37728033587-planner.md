**What it covers:**
- **155.1 Summary:** a new test needs a docstring whose first line is one sentence on one line, ending in `.`, `?` or `!`. Otherwise it is rejected by name. A dot inside the sentence ("1.5 s") is allowed.
- **155.2 Must fail today:** every new test is run. One that passes or is skipped is rejected, and the reason names it and says it "passes today"; if several do, each is named. A test that fails, or errors because the code it needs doesn't exist yet, gets through.
- **155.3 Renames:** a test whose source is unchanged apart from its name is a change. It needs a reason under its old name, and isn't held to the summary or must-fail rules.
