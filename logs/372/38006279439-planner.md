**Agent:** I've handed back a plan for [#372](https://github.com/dokima-dev/dokima/issues/372) (the card shows a code review as running from the moment it is queued). It passes both hand-back checks. Its four new tests in `tests/test_card_running.py` all fail on today's code because the feature is missing, not because anything crashes.

**What I found:** the issue's diagnosis holds, and there is one more cause.
- `code_review()` in `dokima/card.py` only knows a finished review.
- `card.yml` skips every comment the bot posts and every comment on a pull request. The code review's run card is both, so it never redraws the card.
- `card.yml` also redraws only when the full suite *finishes*. That's why All tests never shows running, even though the card already draws an in-progress check as running.

**The plan (four criteria):**
- **372.1** Code review shows running, with `dokima/icons/running.svg`, from the bot's code review run card after the newest build until its record. Before that card it shows not started; after the record it shows passed or failed. A plan review's or worker's run card, an older card from before the newest build, or the same text posted by anyone but the bot leaves it not started.
- **372.2** When the full suite starts on the pull request, both cards are redrawn and show All tests running; once it passes they show passed.
- **372.3** When the bot puts up the code review's run card, both cards are redrawn at once and show Code review running. Any other comment the bot posts on the pull request still redraws nothing.
- **372.4** (non-functional) That redraw waits in the issue's own card queue and never cancels a running one, as [#346](https://github.com/dokima-dev/dokima/issues/346) (each issue's card redraws get their own queue) requires. A comment on a pull request carries the pull request's number, not the issue's, so this needs care.

**Scope:** `dokima/card.py`, `.github/workflows/card.yml`, `AGENTS.md`. Out of scope: the criterion rows' own check circles (the issue is about the Definition of Done) and Owner approval (no running state).
