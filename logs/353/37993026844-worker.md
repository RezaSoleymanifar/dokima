- **When the last blocker closes:** a new function, `start_unblocked`, starts a fresh planner once and posts `Autopilot: blockers merged, starting plan`. The old plan's worker never starts. Nothing starts if something already happened since the approval: a newer record, a run card, an Autopilot line, or the owner's own `/plan`, `/work` or other command. If GitHub can't list the issue's blockers, nothing starts and the issue gets a comment with GitHub's reason.
