- **First refusal:** the bot posts the comment, as before.
- **Later refusals:** the same comment is edited to show the newest main commit and GitHub's newest reason.
- **Pull requests that already have several:** a pull request like #287 gets no new comment; its newest refusal comment is edited and the bot's older ones are deleted.
