**The cause:** the board put an issue in whatever column the next stage would use, without checking that the stage had actually started. **What changed:**

- **`dokima/board.py`:** `where()` uses the newest stage started since the issue's newest record. If nothing has started, the card stays where it is:
  - an approved plan stays in Plan until its worker starts, including while it waits on a blocker;
  - a built issue stays in Work until its code review's run card is up, including after a rebuild.
