- **Worker card (182.3):** the top is one line: the change sentence of the worker's own summary, with a link to its pull request. On the first round the pull request is opened after the record is written, so `agent next` redraws the comment with the link before adding the Next line. If code rejected the hand-back or there was none, the sentence says the worker stopped early and the reasons are listed right below. The cause sentence, the per-criterion lines, its own test run, files changed outside the plan, suspect tests and replies are in folds.
- **Reviewer card (182.4):** it says passed, blocked or escalated. On top it lists only the blockers, each with its criterion and note, plus the judged assumptions and its proposed issues. Everything else is folded.
- **AGENTS.md (182.5):** a new principle, "Match the output to the human brain bottleneck", and the section on agent records now describes the new comment shape.
- **Full record (182.6):** the JSON record is always the last fold, on every comment including runs that never started and cancelled runs, and it reads back exactly.
