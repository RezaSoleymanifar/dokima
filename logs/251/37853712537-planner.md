All five tests in `tests/test_link_lines.py` fail today for the right reason: the card and the planner's run comment draw no link lines yet.

**B1, link icons could be a verdict or run icon:**
- **Criterion 251.1** now says each kind draws its own file in `dokima/icons` (`blocked-by.svg`, `blocks.svg`, `related.svg`), none of them a verdict or run icon.
- **The tests** now name those three files themselves instead of reading them from `card.FIELD_ICONS`. Before, a worker could have mapped "related" to `passed.svg` and still passed.
- **Each link line** must now draw exactly its own icon and no other. A line carrying `passed`, `failed`, `queued`, `running`, `cancelled`, `none` or any other verdict icon fails.
- **A new check** confirms all three icon files exist.

**The reviewer's note:** I also took up their non-blocking point that "draws as it does today" wasn't really proven. As a side effect, a worker can't add a separate "Links" heading even when there are links; the issue doesn't ask for one. I added this only for the issue card, not for the planner's run comment.
