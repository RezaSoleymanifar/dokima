- **235.3:** A merged pull request whose merger is a code owner shows Owner approval passed, even with no Approve review. A merge by anyone else, including the bot on autopilot, doesn't count; then Owner approval follows the owner's reviews as before.
- **235.4:** Both cards always link to the issue and the PR. The PR card is now written whether the pull request is open, merged or closed. That was the cause on #224: once the PR closed, only the issue card kept being redrawn.
- **235.5:** A last line under each criterion, the word "Source", links to where the owner asked for it. The planner's prompt now says to use the most recent place the owner asked. Non-functional requirements use the same bullet shape inside their fold, labelled as non-functional requirements, with no Source line.

`render` still accepts a `page` argument because existing tests pass it, but it no longer changes the output.

The test for picking the most recent ask only reads the planner's prompt for those words. Whether the planner actually links the newest ask can only be judged on later plans.
