**One issue for a separate fix:** in `agent.yml` the reading before the run goes into `$OUT/budget.jsonl`, which the agent can write to while it works. An agent could therefore rewrite the "before" numbers its own record shows. The plan chose that file location, so it isn't a blocker here, and the reading after is safe because it's taken once the agent has finished. Keeping the file outside `$OUT` until the record is written would close the gap.
